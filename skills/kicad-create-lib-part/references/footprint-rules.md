# 封装几何细则（校准数据）

下面每个常数都不是猜的，是在 **KiCad 官方库的真实封装**上逐值对出来的。
改这些常数之前，先跑一遍校准（本文末尾）。

## 校准样本

| 样本 | 本体 | 焊盘 | 丝印 y | 外框 |
|---|---|---|---|---|
| `Package_SO:MSOP-10_3x3mm_P0.5mm` | 3.0 × 3.0 | 1.5 × 0.35 @ x=±2.1 | ±1.61 | 12 段，中段 ±1.75 / 端块 ±1.43 |
| `Package_SO:SOIC-8_3.9x4.9mm_P1.27mm` | 3.9 × 4.9 | 1.95 × 0.6 @ x=±2.475 | ±2.56 | 12 段，中段 ±2.7 / 端块 ±2.46 |

## 1. 丝印框位置

```
丝印半宽 = 本体 / 2 + 0.11
```

* MSOP：1.5 + 0.11 = 1.61 ✓
* SOIC：2.45 + 0.11 = 2.56 ✓

## 2. 丝印被焊盘裁掉 —— 0.26 是怎么来的

丝印线段凡是落进"焊盘膨胀区"的部分都要删掉。膨胀量：

```
裁剪边界 = 焊盘边缘 + 0.2 (KiCad 生成器的 silk/pad 间距)
                     + 0.06 (丝印线宽 0.12 的一半)
         = 焊盘边缘 + 0.26
```

验证：

| 样本 | 焊盘 y 外沿 | +0.26 | 官方文件里的丝印残段起点 |
|---|---|---|---|
| MSOP-10 | 1.0 + 0.175 = 1.175 | **1.435** | 1.435 ✓ |
| SOIC-8 | 1.905 + 0.3 = 2.205 | **2.465** | 2.465 ✓ |

**两个独立封装都吻合到小数点后三位，所以这不是拟合出来的。**

裁完之后的残段短于 `SILK_MIN`（0.05）就丢掉。

## 3. 外框是 12 段十字形，不是矩形

```
bx = 本体宽/2 + 0.25     by = 本体高/2 + 0.25
PX = 焊盘 x 外沿 + 0.25  PY = 焊盘 y 外沿 + 0.25
```

外框 = `[−bx,bx]×[−by,by]` 与 `[−PX,PX]×[−PY,PY]` 的并集轮廓。
因为 `PX > bx` 且 `PY < by`（焊盘在 x 方向伸出去，在 y 方向比本体窄），
轮廓就是 12 段。

MSOP-10 的 12 段（官方文件里的顺序无关，几何一致）：

```
(-1.75,-1.75)->( 1.75,-1.75)   中段上边
( 1.75,-1.75)->( 1.75,-1.43)
( 1.75,-1.43)->( 3.10,-1.43)   右端块上边
( 3.10,-1.43)->( 3.10, 1.43)   右端块右边
( 3.10, 1.43)->( 1.75, 1.43)
( 1.75, 1.43)->( 1.75, 1.75)
( 1.75, 1.75)->(-1.75, 1.75)   中段下边
(-1.75, 1.75)->(-1.75, 1.43)
(-1.75, 1.43)->(-3.10, 1.43)   左端块下边
(-3.10, 1.43)->(-3.10,-1.43)   左端块左边
(-3.10,-1.43)->(-1.75,-1.43)
(-1.75,-1.43)->(-1.75,-1.75)
```

**坑**：不能因为 `PY < by` 就把 `PY` 拉平成 `by`。`PY < by` 正是"两端比中间窄"
这个形状本身；拉平了外框退化成矩形，贴片机的避让区就不准了。

**另一个坑**：`PX ≤ bx`（焊盘没伸出本体，例如 0402）时轮廓退化成一个普通矩形，
要单独分支处理。

## 4. 焊盘 Y 方向：+Y 向下

KiCad 封装坐标系里 **+Y 是向下的**（和原理图相反）。所以：

* pad 1 在**左上** → `y` 是**负**的
* 左边一列从 `−(n−1)/2·pitch` 递增到 `+(n−1)/2·pitch`（从上到下）
* 右边一列反过来，从下往上编号（顺时针数）

官方 SOIC-8 印证：pad 1 在 `(-2.475, -1.905)`，负的。✓

第一版生成器写成 `-y`，后果是 pad1 跑到左下角、和 Pin1 三角标正好相反 ——
几何上完全自洽，所以只有**把生成结果和手写结果逐焊盘比**才发现得了。

## 5. 圆角矩形焊盘

```
roundrect_rratio = 图纸标注的圆角半径 / 焊盘短边
```

TI DGS0010A 图纸标 `(R0.05)`，焊盘 1.45 × 0.3 → `0.05 / 0.3 = 0.166667`。

注意 KiCad 官方库同类封装常用 `0.25`（IPC-7351 另一种密度）。
**两者都合规**，只是密度等级不同。用哪种要在 spec 里明确写出来，
因为将来没人记得为什么是 1.45×0.3 而不是 1.5×0.35。

## 5.5 球阵族（`grid_array`）—— 上面几条都不适用

WLCSP / CSP / BGA / LGA 是另一套。在 `Package_CSP.pretty` 的三个官方封装上
逐值对出来的（`Anpec_WLCSP-20` / `Maxim_WLCSP-35` / `Efinix_WLCSP-64`）：

| 项 | 球阵族 | 上面那套（引脚族） |
|---|---|---|
| 焊盘 | `smd circle` + `(property pad_prop_bga)` | `smd roundrect` |
| 丝印 | 本体/2 + 0.11，被**圆**焊盘裁 | 同（被矩形焊盘裁）|
| 外框 | **矩形**，本体 **+1.0mm/边** | 12 段十字，+0.25 |
| 装配层倒角 | **0.5 × min(本体半宽, 本体半高)** | 固定 0.75 |
| 阻焊开窗 | `(solder_mask_margin)`，按球径取（官方 0.02 / 0.05） | 不写 |
| Pin1 标 | 丝印角点外 **0.5 × 0.5** 三角 | 0.16 / 0.55 |

**外框为什么是 +1.0 而不是 +0.25：** 那是 IPC-7351 对面积阵列封装的**标称**
余量（least / nominal / most = 0.5 / 1.0 / 1.5 mm），球阵要留返修空间。
三个官方封装量出来是 1.000 / 1.005 / 1.002 / 1.002 / 1.000，没有例外。

**倒角为什么是 0.5×min：** 三个官方样本的倒角腿长都等于 0.5 × min(半宽, 半高)：

| 样本 | 半宽 × 半高 | 0.5×min | 官方文件里的倒角腿长 |
|---|---|---|---|
| Anpec-20 | 0.880 × 1.015 | **0.440** | 0.440 ✓ |
| Maxim-35 | 1.499 × 1.084 | **0.542** | 0.542 ✓ |
| Efinix-64 | 1.76765 × 1.68765 | **0.8438** | 0.8438 ✓ |

**焊盘位置不是算出来的：** JEDEC 球名（`A11`、`C7`）本身就把行列编进去了，
`layout_ball_grid()` 直接解字符串。所以符号引脚号和封装焊盘号用的是
同一个字符串 —— 不存在"两处各写一遍然后漂移"这种事。

## 6. 3D 模型

```
(model "${KICAD10_3DMODEL_DIR}/Package_SO.3dshapes/MSOP-10_3x3mm_P0.5mm.step"
```

* 变量名带 KiCad 主版本号（`KICAD10_3DMODEL_DIR`）。换版本要改。
* **模型可以不存在。** 官方库就有这种情况：
  `QFN-32-1EP_5x5mm_P0.5mm_EP3.1x3.1mm.kicad_mod` 指向的 STEP 上游没有。
  校验侧的 `fit3d.py` 会显式报出来，而不是静默出一张没有零件的 3D 图。

## 怎么重新校准

```bash
python - <<'EOF'
import re
p = r"C:\Program Files\KiCad\10.0\share\kicad\footprints\Package_SO.pretty\SOIC-8_3.9x4.9mm_P1.27mm.kicad_mod"
t = open(p, encoding="utf-8").read()
for blk in t.split("(fp_line")[1:]:
    b = blk.split("(fp_")[0]
    if '"F.SilkS"' not in b and '"F.CrtYd"' not in b: continue
    m = re.search(r'\(start ([-\d.]+) ([-\d.]+)\)\s*\(end ([-\d.]+) ([-\d.]+)\)', b)
    lay = "silk" if '"F.SilkS"' in b else "crtyd"
    if m: print(lay, m.groups())
EOF
```

把输出和本文件的数字对一遍。对不上说明 `SILK_OFF` / `COPPER_CLR` / `CRTYD`
这三个常数被改坏了。

球阵族那份要另外量（`Package_CSP.pretty` 里任意一个 WLCSP）：

```bash
python - <<'EOF'
import re, glob
p = glob.glob(r"C:\Program Files\KiCad\10.0\share\kicad\footprints\Package_CSP.pretty\*WLCSP*.kicad_mod")[0]
t = open(p, encoding="utf-8").read()
print(re.search(r'_(\d+\.\d+)x(\d+\.\d+)mm', p).groups(), "<- 本体 D x E")
print(set(re.findall(r'\(pad "[^"]+" smd (\w+)', t)), "<- 焊盘形状（应只有 circle）")
print(re.findall(r'\(fp_rect\s*\(start ([\-\d.]+) ([\-\d.]+)\)\s*\(end ([\-\d.]+) ([\-\d.]+)\)[\s\S]{0,140}?F\.CrtYd', t), "<- 外框")
EOF
```

外框半宽减本体半宽应当接近 **1.00mm**；倒角腿长应当是短的那半边的一半。
